## Training pipeline

This is the main case study for the project that tracks safety talks and other training activities. It explains how operational data entry, the database, and the dashboard connect to transform a recorded activity into information for management.

- [Training pipeline](./pipeline_capacitaciones/)

The pipeline is supported by complementary case studies:

- [Training database - Data modeling in SQLite](./capacitaciones.db/): database design, historical records, catalogs, views, indexes, and data rules.
- [Training - Tracking dashboard](./capacitaciones/): how the dashboard works, its calculations, indicators, visualizations, and reports.
- [Dashboard evolution](./capacitaciones/actualizacion/): navigation redesign and generation of weekly HTML reports for each coordinator.

The pipeline serves as an entry point for understanding the complete solution. The other documents provide a closer look at each component without repeating the entire implementation in a single README.
